# Vietlott 5/35 Predictor

Ứng dụng dự đoán kết quả xổ số Vietlott 5/35

## 🎯 Tính Năng

- ✅ Dự đoán số ngẫu nhiên theo thống kê
- ✅ Kiểm tra trúng thưởng
- ✅ Lưu lịch sử dự đoán
- ✅ Thống kê dự đoán
- ✅ Giao diện thân thiện

## 🚀 Cách Sử Dụng

1. Nhấn nút "Dự Đoán" để tạo dự đoán mới
2. Nhập 5 số thực tế (cách nhau bằng dấu phẩy)
3. Nhấn "Kiểm Tra" để xem có trúng thưởng không
4. Xem lịch sử dự đoán trong mục "Lịch Sử"

## 📥 Tải APK

APK được build tự động trên GitHub Actions. Hãy đến tab **Actions** để tải file APK.

## 🛠️ Hướng Dẫn Build

```bash
./gradlew assembleDebug
```
